📋 Petunjuk Penggunaan Template Pamflet

  • Ukuran ideal untuk TV: 960x540 pixel (16:9 landscape) atau 540x960 pixel (9:16 portrait)
  • Format file: JPG atau PNG
  • Letakkan file di folder: public/images/promo/
  • Edit konfigurasi di: app/(public)/agenda/tv/media-config.js
  • Refresh halaman TV untuk melihat perubahan
  • Gunakan warna yang kontras agar terbaca dari jauh
  • Font minimal 24px untuk keterbacaan di TV
